# Simple Chess Pairing Software ♟️

A lightweight Swiss-system chess tournament pairing application built using Flask and SQLite.

## 💡 Motivation

This project started with a simple problem: managing chess tournaments using existing Swiss-system pairing software often meant dealing with paid tools.

Instead of relying on them, we decided to build our own solution.

Developed during our first year of engineering, this was one of my first major software development projects and an opportunity to explore backend development through a real-world use case.

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Database:** SQLite
- **Architecture:** Flask application with database integration

## ✨ Project Highlights

- Swiss-system chess tournament pairing
- Tournament management functionality
- Login interface
- Database-backed application

## 📚 What I Learned

- Building a web application using Flask
- Backend development and application structure
- SQLite database integration
- Implementing software to solve an actual problem
- Working with Git and GitHub
